# Приложение для трекинга привычек

## 📋 Описание
Приложение помогает пользователям формировать полезные привычки и отслеживать их выполнение. Оно предоставляет удобный интерфейс для управления привычками, отображения прогресса и статистики.

---

## 🚀 Основной функционал

### 1. Список задач
- **Просмотр трекеров**: отображение списка привычек с названиями, описаниями, датами и статусом выполнения.
- **Создание трекеров**: 
  - Привычки с расписанием на дни недели.
  - Нерегулярные события без привязки к дням.
- **Редактирование трекеров**: возможность менять название, категорию, расписание, эмодзи и цвет.
- **Удаление трекеров**: полное удаление привычки вместе с данными.
- **Поиск и фильтры**: 
  - Поиск трекеров по названию.
  - Фильтры: все трекеры, сегодняшние, выполненные и невыполненные.

---

### 2. Главный экран
- **Кнопка «+»** для добавления привычки или нерегулярного события.
- **Сортировка**: карточки трекеров отсортированы по категориям.
- **Календарь**: просмотр запланированных трекеров на выбранную дату.
- **Подсчет прогресса**: отображение количества выполненных дней для каждого трекера.
- **Интерактивность**:
  - Кнопка выполнения привычки.
  - Возможность закрепления трекеров в верхней части списка.
- **Редактирование**:
  - Возможность редактировать название, расписание, категорию и другие параметры.
  - Удаление трекеров с подтверждением действия.
  
---

### 3. Создание и редактирование трекеров
- **Экраны создания и редактирования**:
  - Поле ввода названия (максимум 38 символов).
  - Выбор категории, эмодзи и цвета.
  - Настройка расписания (для привычек).
- **Пользовательский опыт**:
  - Если разделы не заполнены, кнопка «Создать» неактивна.
  - Ошибки отображаются при превышении допустимого количества символов.
  - Сохранение изменений возвращает пользователя на главный экран.

---

### 4. Фильтры и поиск
- **Фильтры**: 
  - Все трекеры.
  - Текущие задачи на выбранный день.
  - Завершенные и невыполненные трекеры.
- **Поиск**:
  - Быстрая фильтрация списка по названию.
  - Заглушка при отсутствии результатов.

---

### 5. Статистика
- Отображение данных по следующим показателям:
  - **Лучший период**: максимальное количество дней без перерыва.
  - **Идеальные дни**: дни, когда выполнены все привычки.
  - **Трекеров завершено**: общее количество выполненных задач.
  - **Среднее значение**: среднее количество завершенных трекеров за день.
- Если данных нет, отображается заглушка.

---

### 6. Темная тема
- Приложение автоматически адаптируется под системные настройки устройства (светлая/темная тема).

---

## 🎨 Онбординг
- Первый запуск приложения сопровождается экраном онбординга с информацией о возможностях.
- Свайпы переключают экраны.
- Кнопка «Вот это технологии» переходит на главный экран.

---

## 🛠️ Редактирование и удаление категорий
- **Редактирование категорий**: возможность изменить название категории.
- **Удаление категорий**: подтверждение действия перед удалением всех данных, связанных с категорией.
